SMART POS SUPABASE V4 — CLEAN BASELINE
=====================================

การจัดระเบียบรุ่นนี้
- รวม SQL ติดตั้งและ RPC ขั้นสุดท้ายไว้ใน SMARTPOS_V4_ONE_RUN_INSTALL.sql เพียงไฟล์เดียว
- ตัดไฟล์ migration ระหว่างทาง 08–14, SQL health-check, SQL reconciliation และไฟล์ .reference ที่ซ้ำออกจากแพ็กเกจ
- รวม local_id mapping, get_my_store(), product_fractions และ set_variant_stock() เข้ากับ schema หลัก
- รวมรับสินค้าเข้าและคืนสินค้า พร้อม VAT และการคำนวณยอดคืนแบบเก็บเศษสตางค์
- รวมการยกเลิกบิล, sale_voids และ payment_reversals โดยเก็บ payment เดิมไว้เป็นหลักฐาน
- ใช้ process_sale_atomic รุ่นสุดท้ายเพียงนิยามเดียว รองรับ idempotency, ล็อกสต็อก, ตรวจราคาจากฐานข้อมูล,
  ตรวจยอด/VAT และหน่วยแบ่งขาย
- คงไฟล์แอปหลักเดิมไว้ และรวมเฉพาะ adapter ที่จำเป็นสำหรับเชื่อมกับ Supabase V4

การตรวจสอบที่ทำแล้ว
- ตรวจ JavaScript ทุกไฟล์ด้วย node --check
- ตรวจโครงสร้าง SQL แบบ static (RPC สำคัญแต่ละตัวมีนิยามเดียว, dollar quote คู่ครบ,
  schema หน่วยย่อย/VAT/ยกเลิกบิลครบ)

ข้อจำกัด
- ไม่ได้เชื่อมต่อฐานข้อมูล Supabase จริง และไม่ได้ execute SQL บน PostgreSQL ของผู้ใช้
- ต้องติดตั้ง/ทดสอบใน Supabase โปรเจกต์ใหม่ก่อนใช้งาน production


รอบปรับปรุงแค็ตตาล็อกสินค้า
----------------------------
- เพิ่ม 10-product-catalog-import-export.js สำหรับส่งออก JSON แบบครบชุดและ CSV ที่แก้ไขใน Excel ได้
- รองรับสินค้า หมวดหมู่ กลุ่มสินค้า หลายรุ่น/ขนาด บาร์โค้ด SKU ต้นทุน ราคาขาย หน่วย หน่วยแบ่งขาย รูป URL/Storage path และสถานะสินค้า
- JSON เลือกฝังรูปเป็น data URL เพื่อย้ายข้ามร้านได้เมื่อเบราว์เซอร์อ่านรูปได้; CSV รองรับการเลือกไฟล์รูปหลายไฟล์แยกต่างหาก
- เพิ่มตรวจข้อมูลซ้ำ/ค่าติดลบก่อนนำเข้า; ใช้ merge แบบไม่ลบรายการเดิม และไม่เขียนทับสต็อกเว้นแต่ผู้ใช้เลือกชัดเจน
- ตัวเลือกนำเข้าสต็อกเรียก set_variant_stock RPC เพื่อรักษาประวัติ stock_movements และสิทธิ์ role
- เพิ่ม PRODUCT_IMPORT_TEMPLATE.csv และเอกสารขั้นตอนใน README-INSTALL-TH.txt
- ตรวจไวยากรณ์ JavaScript แล้ว; ยังต้องทดสอบ UI, Storage policy และการซิงค์กับ Supabase staging จริงก่อนใช้งาน production


รุ่น 2.0 — ระบบนำเข้า/ส่งออกสินค้าแบบตรวจสอบรายแถว
--------------------------------------------------
- ขยาย CSV ให้เก็บแบรนด์ รายละเอียดสินค้า ต้นทุนปัจจุบัน/ล่าสุด สถานะรุ่น และเปอร์เซ็นต์กำไรขั้นต่ำ
- เพิ่มการตรวจตัวเลขผิดรูปแบบ จำนวนคอลัมน์ รหัสรุ่น บาร์โค้ด และ SKU ซ้ำ
- เพิ่มโหมดนำเข้าเฉพาะกลุ่มสินค้าที่ผ่านการตรวจสอบ และรายงานข้อผิดพลาด CSV ที่มีเลขแถว
- เพิ่มความคืบหน้าการนำเข้า และคงรายงานข้อผิดพลาดไว้หลังนำเข้าสินค้าส่วนที่ผ่านแล้ว
- เพิ่มการจับคู่สินค้าเดิมด้วย SKU และนำเข้าหมวดหมู่จาก JSON
- ทดสอบตัวอย่าง CSV ที่มีข้อมูลถูกต้องและแถวผิดพลาด: สินค้าถูกต้องนำเข้าในชุด valid ได้ และกลุ่มผิดพลาดถูกแยกในรายงาน
